ABOUT ME

Learning to navigate
with limited observations.

I’m Ziyu Wang, a Computer Science undergraduate in the Turing Class at Southern University of Science and Technology.

My research focuses on vision-and-language navigation: how an embodied agent can turn visual observations and language instructions into reliable actions in unfamiliar environments.

I’m currently exploring how richer visual context can supervise a navigation policy that uses only monocular RGB, visual history, and language at deployment. I also study navigation failure cases and the reliability of self-supervision for test-time adaptation.

  • Vision-and-language navigation
  • Robot learning
  • Knowledge distillation

Ongoing research01 / NAVIGATION

Panorama-OPSD

On-policy self-distillation for monocular navigation

Designing a teacher–student framework that uses panoramic context during training to guide a navigation policy operating with a single forward-facing camera.

Research approach +

The proposed design first jointly fine-tunes a shared policy on paired panoramic and monocular observations with the same expert-action labels. A frozen panoramic copy then supervises the monocular student on the student’s own sampled action prefixes.

Current stage: framework development and preliminary pipeline validation. Next steps: policy training and distillation evaluation.

  • Privileged visual context
  • Teacher–student learning
  • VLN-CE

Understanding navigation failures

Failure analysis, learned action scoring & test-time adaptation

Reviewed VLN foundation models and analyzed their failure cases. Trained and evaluated scorers for eight action candidates from a frozen NaVIDA policy, comparing prediction and ranking objectives with action-only and state-conditioned baselines.

Currently exploring reliable self-supervised parameter updates using monocular RGB, visual history, and language instructions.

  • Failure analysis
  • Action scoring
  • Test-time adaptation
